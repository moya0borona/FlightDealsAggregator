
Приложение-агрегатор полётов, использующее Travelpayouts API
---
## Основной функционал
- **Список рейсов**
- **Фильтры**
- **Детали рейса**
- **Динамическая верстка**
- Камера
- ## Стек
- Swift 5  
- SwiftUI  
- MVVM + Combine
- async/await
