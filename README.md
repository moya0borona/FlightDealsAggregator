
Приложение-агрегатор полётов, использующее Travelpayouts API
---
### Основной функционал
- **Список рейсов**
- **Фильтры**
- **Детали рейса**
- **Камера**
### UI
- **Динамическая верстка**
- **Анимация списка**
### Стек
- Swift 5  
- SwiftUI  
- MVVM + Combine
- async/await
